# Pla inicial per a Shiny Moon Glass

## Objectiu

Substituir la pàgina provisional de `shinymoonglass.com` per una web pròpia que presenti l'univers de la botiga i dirigeixi cada visita cap a l'acció comercial correcta.

La base actual és una landing estàtica amb aparença de catàleg. No conté base de dades, autenticació, formularis, passarel·la de pagament, analítica ni gestió de comandes.

## Fases recomanades

1. **Identitat i landing.** Logo, paleta, fotografies, proposta de valor, sobre nosaltres, contacte i enllaços socials o de compra.
2. **Aparador de col·leccions.** Pàgines per a les categories reals, galeria d'obres i fitxes de producte informatives.
3. **Venda.** Integració amb la plataforma que es decideixi; inclou preus, disponibilitat, enviaments, devolucions i pagament.
4. **Creixement.** SEO, newsletters, analítica amb consentiment, contingut editorial i automatitzacions només si aporten valor.

## Decidir abans de la fase 2

- Què es ven: peces acabades, comandes personalitzades, kits, patrons digitals o diverses línies.
- On es completa la compra: web pròpia, Shopify, Etsy, contacte directe o una combinació.
- Idiomes de llançament i llengua per defecte.
- Àrea de lliurament, transportistes, costos i política de devolucions.
- Canal de contacte i termini de resposta.
- Qui actualitza productes, fotos i disponibilitat.

## Criteri de llançament

Publica primer una versió petita però coherent: marca definitiva, missatge clar, fotos pròpies, forma de contacte i una acció comercial funcional. Una web sense cistella pot ser una primera versió vàlida si el camí de compra o d'encàrrec és explícit i respon realment a les visites.
