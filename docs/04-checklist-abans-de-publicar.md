# Checklist abans de publicar a shinymoonglass.com

## Identitat i contingut

- [ ] No queda cap menció de “Simple Glass Patterns” ni “SGP” al codi publicat.
- [ ] S'han reemplaçat totes les URL d'Etsy, Pinterest, email i xarxes que no corresponguin a Shiny Moon Glass.
- [ ] S'han substituït logo, favicon, metadades, fotos, textos alternatius i descripcions SEO.
- [ ] Les imatges tenen autorització d'ús i les seves descripcions alternatives expliquen el contingut.
- [ ] Els preus, productes, disponibilitat i condicions de compra són reals i revisats.

## Tècnic

- [ ] `npm run lint` finalitza correctament.
- [ ] `npm run typecheck` finalitza correctament.
- [ ] `npm run build` finalitza correctament.
- [ ] S'ha revisat la web en mòbil, tauleta i escriptori.
- [ ] Tots els botons, el correu i els enllaços externs obren el destí correcte.
- [ ] El desplegament de prova funciona abans de tocar el domini principal.
- [ ] `shinymoonglass.com` i `www.shinymoonglass.com` s'han configurat amb HTTPS i la redirecció preferida.

## Comerç, privacitat i legal

- [ ] S'ha definit qui ven, a quins països i amb quines condicions.
- [ ] Si es venen productes directament, la informació de preus, impostos, enviaments, devolucions i contacte és adequada per als mercats objectiu.
- [ ] Si hi ha formularis, newsletter, analítica o píxels, s'ha revisat la privacitat, el consentiment i la política de cookies aplicables.
- [ ] S'han afegit les pàgines legals necessàries abans de tractar dades personals o acceptar pagaments.

No és assessorament legal. Abans d'obrir la venda directa, valida aquests punts amb la persona o professional que porti l'activitat.
