# Shiny Moon Glass

Web de presentació de Shiny Moon Glass. Aquesta primera base conserva temporalment l'estructura i part del contingut de Simple Glass Patterns mentre es construeix la identitat pròpia.

## Desenvolupament

```bash
npm run dev
```

El servidor de desenvolupament s'obre a [http://localhost:3002](http://localhost:3002).

## Comprovacions

```bash
npm run lint
npm run typecheck
npm run build
```

La documentació de producte i les decisions inicials són a [`docs/`](docs/).
